# Plagirism-Checker

This Python-based Plagiarism Checker is designed to detect similarity between multiple text documents by comparing their content using natural language 
processing and string-matching techniques.It allows users to upload or input multiple files, and then checks them for overlapping or copied content,
displaying a similarity score for each pair.

🔧 Features:
Upload and analyze multiple .txt, .pdf, or .docx files

Calculate similarity using algorithms like Cosine Similarity or Jaccard Index

Highlights matched or copied sections (optional)

Generates a detailed plagiarism report

User-friendly CLI or optional GUI using Tkinter/Streamlit

🧠 Tech Stack:
Language: Python

Libraries: scikit-learn, NLTK, difflib, tkinter or streamlit, PyPDF2 / docx (for file handling)

💡 Use Cases:
Academic institutions for student assignments

Content writers checking originality

Developers verifying code or documentation reuse
